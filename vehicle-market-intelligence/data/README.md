# Sample data

`cars_sample.csv` retains the first 100 records and 22 dashboard-relevant fields from the user-supplied `cars_dataset.csv`. It is not a random sample. The full source contains 100,000 records and 437 columns and is approximately 233 MB. Source provenance, licensing, currency and real/synthetic status are unconfirmed. The sample is supplied only to reproduce this learning dashboard; no broader reuse license is asserted.
